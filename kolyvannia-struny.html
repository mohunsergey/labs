Теоретичні відомості та опис приладів

Внаслідок накладання біжучої і відбитої хвилі утворюється стояча хвиля. Якщо за початок координат взяти точку, в якій біжуча і відбита хвилі мають однакову фазу, а за початок відліку часу той момент, коли фази обох коливань дорівнюють нулю, то рівняння біжучої і відбитої хвилі мають вигляд:

ξ₁ = A₀ sin(ωt − 2πx/λ), ξ₂ = A₀ sin(ωt + 2πx/λ)

Результуюче коливання знаходимо, додавши два коливання:

ξ = ξ₁ + ξ₂ = 2A₀ cos(2πx/λ) · sin ωt (1)

Рівняння (1) є рівнянням стоячої хвилі. З нього видно, що амплітуда коливального руху змінюється при переході від однієї точки до іншої:

A = 2A₀ |cos(2πx/λ)| (2)

У точках, для яких виконується умова

(2π/λ)·x = nπ, n = 0, 1, 2, 3 … (3)

амплітуда результуючого коливання досягає максимального значення 2A₀. Ці точки називають пучностями. Їхні координати:

xпучн = n·λ/2, n = 0, 1, 2, 3 … (4)

Віддаль d між двома сусідніми пучностями дорівнює половині довжини хвилі: d = λ/2. У точках, для яких виконується умова

(2π/λ)·x = (n + ½)π, n = 0, 1, 2, 3 … (5)

амплітуда коливання в будь-який момент часу дорівнює нулю. Такі точки називаються вузлами стоячої хвилі. Їхні координати:

xвузл = (n + ½)·λ/2, n = 0, 1, 2, 3 … (6)

Віддаль між двома сусідніми вузлами також дорівнює половині довжини хвилі:

d = λ/2 (7)

Відстань між сусіднім вузлом і пучністю дорівнює чверті довжини хвилі. Частинки, що лежать між двома сусідніми вузлами, коливаються в однакових фазах, а по різні боки від вузла в протилежних.

Швидкість поширення хвиль у натягнутому шнурі (натягнутій струні) залежить від сили натягу F і густини шнура:

v = √( F / (S·ρ) ) (8)

де F — сила натягу струни, S — площа її поперечного перерізу, ρ — густина матеріалу струни. З формули (8) видно, що швидкість поширення хвилі пропорційна кореню квадратному із сили натягу. Довжина хвилі дорівнює добутку швидкості на період:

λ = v·T (9)

Оскільки T = 1/ν, де ν — частота, то

λ = v / ν (10)

Звідси швидкість поширення хвилі:

v = λ·ν (11)

Порядок виконання роботи

  1. Підключити установку до електромережі. Натиснути кнопку «Мережа» пристрою живлення лампи (коробка під корпусом). Після цього повинна засвітитись лампа підсвічування струни.
  2. Натиснути кнопку «Мережа» вимірювального пристрою (генератора). Після цього повинно засвітитись цифрове табло.
  3. Дати установці прогрітись протягом 5 хв. У моделі прогрів можна прискорити кнопкою, але до його кінця показання табло трохи відрізняються від справжньої частоти.
  4. Встановити натяг струни 0,4 Н. Ручку «Рівень» поставити в середнє положення. Змінюючи частоту в межах 20–45 Гц, одержати одну півхвилю на всій довжині струни.
  5. Виміряти віддаль d між сусідніми вузлами та частоту ν коливань струни. У моделі для цього курсор на шкалі наводять на кожен вузол (місце, де струна нерухома) й натискають «Позначити вузол». Позначають усі вузли, включно з кінцями струни.
  6. Змінюючи частоту, отримати на струні дві, три, чотири пучності й щоразу вимірювати віддалі d між вузлами та частоту, за якої утворюється стояча хвиля. Якщо потрібна частота виходить за межі діапазону, перемкніть його перемикачем.
  7. Повторити дослідження, описані в пунктах 5–6, при інших силах натягу струни.
  8. Результати вимірювань занести в таблицю 1а.
  9. За формулою (7) обчислити довжину хвилі: λ = 2d̄.
  10. Обчислити швидкість поширення хвилі за формулою (11).
  11. Результати обчислень занести в таблицю 1б. Оцінити похибки вимірювань.
  12. Побудувати графік залежності v = f(√F).
  13. За графіком і за формулою (8) визначити густину струни.

Таблиці 1а, 1б і 2 та графік на вкладці «Обробка» заповнюються автоматично за записами журналу. Площа перерізу струни S = πd²/4, де діаметр дроту d = 0,15 мм.

Обробка результатів вимірювань

⟨v⟩ = (v₁ + … + vₙ) / n, Δvᵢ = vᵢ − ⟨v⟩
Sv = √( ΣΔvᵢ² / (n(n−1)) )
Δv = tα,n·Sv, E = Δv / ⟨v⟩ · 100 %

Коефіцієнт Стьюдента tα,n береться для надійності α = 0,95. Із (8) випливає v = k√F, де k = 1/√(ρS). Кутовий коефіцієнт прямої, проведеної через початок координат, дає k, звідки ρS = 1/k², а густина ρ = 1/(k²S).
