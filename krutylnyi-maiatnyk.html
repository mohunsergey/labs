Теоретичні відомості та опис приладів

В роботі перевіряються співвідношення для осей, що проходять через геометричний центр тіла. Момент інерції твердого тіла відносно осі, заданої одиничним вектором n = (cos α, cos β, cos γ), де α, β, γ — кути між напрямом вектора і координатними осями OX, OY, OZ, пов'язаний з головними моментами інерції співвідношенням:

I(n) = Ixcos²α + Iycos²β + Izcos²γ (1)

Досліджуване тіло жорстко закріплюють у рамці, підвішеній на пружній вертикально натягнутій дротині. Якщо вивести маятник із положення рівноваги, він здійснює крутильні коливання з періодом

T = 2π·√(Iм / D) (1а)

де Iм — момент інерції маятника відносно осі обертання, D — стала моменту пружних сил. Момент інерції маятника дорівнює сумі моментів інерції рамки I₀ та досліджуваного тіла I: Iм = I₀ + I. Період коливань маятника з тілом і без нього:

T = 2π·√((I₀ + I) / D) (2)
T₀ = 2π·√(I₀ / D) (3)

Виключивши сталу D з (2) і (3), одержимо момент інерції тіла відносно осі маятника через момент інерції вільної рамки I₀ і виміряні періоди T₀ та T:

I = I₀·(T² − T₀²) / T₀² (4)

Оскільки момент інерції тіла залежить від його орієнтації відносно осі маятника, то і період залежить від цієї орієнтації. В установці вісь маятника вертикальна, тому для осі, заданої вектором n, маємо

I(n) = I₀·(T²(n) − T₀²) / T₀² (5)

Якщо вісь обертання збігається з однією з головних осей OX, OY, OZ тіла, то

Ix = I₀·(Tx² − T₀²) / T₀²
Iy = I₀·(Ty² − T₀²) / T₀² (6)
Iz = I₀·(Tz² − T₀²) / T₀²

Підставивши (5) і (6) у (1) і врахувавши, що cos²α + cos²β + cos²γ = 1, одержимо зв'язок між періодом коливань відносно довільної осі і періодами відносно осей симетрії:

T²(n) = Tx²cos²α + Ty²cos²β + Tz²cos²γ (7)

Формула (7) справедлива за малого згасання. Практично для цього достатньо, щоб кількість коливань N, за які амплітуда зменшується у 2–3 рази, була не меншою за 10: N ≥ 10. Залежність (7) перевіряється для тіл форми прямокутного паралелепіпеда з ребрами a, b, c.

а) Однорідний куб (a = b = c). Всі три головні моменти однакові (Ix = Iy = Iz), тому момент інерції куба відносно будь-якої осі, що проходить через його центр, не змінюється, а період коливань не залежить від положення осі:

I(n) = Ix(cos²α + cos²β + cos²γ) = Ix = const (8)
T(n) = Tx = const (9)

б) Симетричний прямокутний паралелепіпед (a = b ≠ c). Тоді Ix = Iy і Tx = Ty:

Ix = Iy, Tx = Ty (10)
I(n) = Ix(1 − cos²γ) + Izcos²γ (11)
T²(n) = Tx²(1 − cos²γ) + Tz²cos²γ (12)

Період залежить лише від кута γ між віссю обертання і віссю тіла OZ. Для будь-якої осі в площині XOY (γ = π/2) cos γ = 0 і

T(n) = Tx = const (13)

Тобто, коли вісь обертання перпендикулярна до великого ребра, періоди коливань за будь-якого положення тіла мають збігатися.

в) Несиметричний паралелепіпед. Закріпимо паралелепіпед так, щоб вісь обертання збігалася з головною діагоналлю AB. Обчисливши напрямні косинуси, із (7) знайдемо:

TAB²(a² + b² + c²) = Tx²a² + Ty²b² + Tz²c² (14)

Аналогічно для осей EF, MN і PQ (рис.):

TEF²(b² + c²) = Ty²b² + Tz²c²
TMN²(a² + c²) = Tx²a² + Tz²c² (15)
TPQ²(a² + b²) = Tx²a² + Ty²b²

Визначення моменту інерції тіла. Вимірявши момент інерції I₀ вільної рамки, можна визначити момент інерції I(n) будь-якого тіла за формулами (5) і (6). Для визначення I₀ використовують еталонне тіло з відомим моментом інерції Iе. Згідно з (4):

I₀ = Iе·T₀² / (Tе² − T₀²) (16)

де Tе — період коливань рамки з еталоном. Еталоном слугує однорідний куб, момент інерції якого відносно осі через центр дорівнює

Iе = m·a² / 6 (17)

де m — маса куба, a — його ребро.

Перевірка теореми Штейнера. Момент інерції тіла відносно довільної осі дорівнює сумі моменту інерції Iц відносно паралельної осі, що проходить через центр мас, і добутку маси тіла на квадрат відстані між осями:

I = Iц + m·l² (18)

Для перевірки визначають I₀ за (16), закріплюють тіло так, щоб вісь коливань проходила через центр мас, вимірюють період і обчислюють Iц за формулою

Iц = I₀·(Tт² − T₀²) / T₀² (19)

де T₀ — період вільної рамки, Tт — період рамки з тілом. Потім закріплюють тіло так, щоб вісь не проходила через центр мас, знову вимірюють період і за (19) визначають момент інерції відносно нової осі. Виміряна відстань між осями l і маса тіла дають змогу перевірити (18).

Порядок виконання роботи

Переконайтеся, що коливання маятника слабо згасають. Для цього виведіть маятник із положення рівноваги й визначте кількість коливань N, за які амплітуда зменшиться у 2–3 рази (на вкладці «Дослід» це видно під графіком θ(t); зручно увімкнути швидкість 30×). Вимірювання проводьте як для вільної рамки, так і для рамки з тілом. Якщо N ≥ 10, згасання мале й можна користуватись формулою (1а). Щоб виміряти період: натисніть МЕРЕЖА, «Відхилити рамку», СКИДАННЯ, ПУСК. Секундомір зупиниться після заданої кількості періодів. Результат запишіть у журнал.

  1. Визначити періоди коливань, закріплюючи в рамці куб у різних положеннях. Результати занести в таблицю 1а: вісь через центри двох протилежних граней (T1, T2, T3); вісь через центри двох протилежних ребер (T4, T5, T6); вісь по головних діагоналях куба (T7, T8, T9, T10).
  2. Визначити період коливань однорідного симетричного паралелепіпеда, закріплюючи його в чотирьох різних положеннях так, щоб вісь обертання була перпендикулярна до великого ребра. Результати занести в таблицю 1б.
  3. Виміряти довжини ребер паралелепіпеда. Визначити період коливань однорідного несиметричного паралелепіпеда відносно його головних осей (Tx, Ty, Tz) та відносно осей AB, EF, MN, PQ (рис.). Результати занести в таблицю 1в.
  4. За формулою (16) визначити момент інерції ненавантаженої рамки I₀. Еталон — однорідний куб, Iе визначити за формулою (17), період Tе = ⟨T⟩ взяти з таблиці 1а. За формулами (6) обчислити моменти інерції несиметричного паралелепіпеда Ix, Iy, Iz. Перевірити виконання рівностей (14) та (15). Результати занести в таблицю 1г.
  5. Перевірити теорему Штейнера (18), використавши несиметричний паралелепіпед. Закріпити його так, щоб вісь обертання була паралельна осі OX, і визначити період T. Момент інерції відносно цієї осі знайти за формулою I = I₀(T² − T₀²)/T₀² (формула (4)), де I₀ і T₀ — момент інерції та період ненавантаженої рамки (таблиця 1г).
  6. Виміряти відстань між осями l та обчислити момент інерції тіла за формулою (18). Результати вимірювань і обчислень занести в таблицю 1д. Порівняти значення моменту інерції, обчислені за формулами (18) та (4). Зробити висновки.

Таблиці 1а–1д на вкладці «Обробка» заповнюються автоматично за записами журналу. Маси й розміри тіл узято з даних лабораторного набору.
